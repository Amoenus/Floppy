{% comment %} Restores scroll position and loaded-episode extent when a user returns to the episode list (#episodes-list) via the browser Back button. The page is always freshly server-rendered on back-navigation (see the pageshow/persisted reload in media_details.html and htmx.config.historyCacheSize = 0 in base.html), so native scroll restoration has nothing to restore into and any "Show more"/infinite scroll content loaded before navigating away is gone. This script saves {scrollY, batches} to sessionStorage before the user clicks into an episode, then on the next load replays that many load-more steps before restoring scrollY. Include once per page that renders #episodes-list. {% endcomment %}
